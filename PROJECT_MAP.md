# Project map

- `backend/app/api/main.py` — FastAPI documents/runs/SSE/artifacts/evidence/resume/cancel + on-demand triple-map API.
- `backend/app/harness/runtime.py` — long-lived goal-oriented Research Director and terminal scientific invariants.
- `backend/app/agents/factory.py` — runtime `AgentSpec` → isolated ephemeral PydanticAI specialist + recovery/escalation.
- `backend/app/agents/toolsets.py` — narrow specialist FunctionToolsets.
- `backend/app/corpus/parsers.py` — GROBID/Docling/PyMuPDF adapters → versioned DocumentIR.
- `backend/app/services/retrieval.py` — non-embedding SQLite FTS5/structural evidence retrieval.
- `backend/app/services/ontology.py` — immutable official DBLP seed + run-local snapshots/proposals.
- `backend/app/services/sparql.py` — semantic-pattern generation/validation support.
- `backend/app/services/edc.py` — evidence-first Extract/Define/non-embedding Canonicalize.
- `backend/app/services/entities.py` — separate entity normalization.
- `backend/app/services/verification.py` — independent multidimensional triple verification.
- `backend/app/services/validation.py` — ephemeral RDF/SHACL structural checks only.
- `backend/app/storage/` — immutable artifacts + SQLite run/event registry.
- `backend/app/telemetry/` — manual redacted OpenTelemetry/Langtrace spans.
- `frontend/` — research console, live trace, evidence/artifact/ontology/SPARQL/triples/run views.
